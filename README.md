## introduction
## 技术栈

- **语言与脚手架**: JavaScript (ESNext) + Create React App (`react-scripts`)
- **前端框架**: React `^18.x` (`react`, `react-dom`)
- **状态管理**: Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **路由**: `react-router-dom` (v6)
- **UI 组件库**: Ant Design (`antd`, `@ant-design/icons`)
- **HTTP 客户端**: `axios`
- **图表**: `echarts`
- **日期处理**: `dayjs`
- **Mock / 本地服务**: `mockjs`, `express`
- **测试**: `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`
- **构建/部署工具（开发依赖）**: `@babel/plugin-proposal-private-property-in-object`, `gh-pages`

## 项目结构（摘要）

- `src/api/`：网络请求与 mock 数据
- `src/components/`：通用组件（侧边栏、头部、标签等）
- `src/pages/`：页面组件（主布局、首页、用户、商品等）
- `src/store/`：Redux store 与 reducers
- `src/router/`：路由配置
